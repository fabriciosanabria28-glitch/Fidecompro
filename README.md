# Fidecompro

Sistema de facturación desarrollado en Java utilizando Java Swing.

## Funcionalidades

- Registro y administración de clientes.
- Registro y administración de productos.
- Control de inventario.
- Generación de facturas.
- Cálculo de impuestos y totales.
- Historial de facturas.
- Exportación de facturas en formato TXT.

## Tecnologías

- Java
- Java Swing
- NetBeans
- Git y GitHub
